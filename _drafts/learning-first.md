这是一篇本地预览用的学习记录示例，不会随正式构建发布。

## 先提出问题

同步代码、微任务与计时器，究竟按什么顺序执行？与其只记住结论，我更想从一段可以运行的代码开始。

```javascript
console.log('开始');
setTimeout(() => console.log('计时器'), 0);
Promise.resolve().then(() => console.log('微任务'));
console.log('结束');
```

### 写下预测

预期输出为“开始 → 结束 → 微任务 → 计时器”。这里讨论的是这段代码的执行顺序，不是所有运行环境下所有任务的通用优先级。

## 动手验证

| 步骤 | 做什么 | 留下什么 |
| --- | --- | --- |
| 预测 | 不运行，写出顺序 | 一份可验证的猜想 |
| 实验 | 在本地运行代码 | 实际输出 |
| 解释 | 找出与猜想的差异 | 修正后的理解 |

> 一次解释不清楚的停顿，往往比十次流畅地读过去更有价值。
